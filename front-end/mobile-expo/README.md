# Hello World

A minimal Expo + React Native app with TypeScript, showing a centered Hello World message.

## Run

From this directory:

```sh
npm install
npm start
```

Scan the QR code with a compatible Expo Go app, or press `a` for an Android emulator or `i` for the iOS simulator. You can also run `npm run web` to open the app in a browser.

Edit `App.tsx` to get started. Run `npm run typecheck` to check TypeScript.
